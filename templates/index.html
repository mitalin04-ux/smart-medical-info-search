    How KMP Searches Symptoms

    Understanding the linear pattern matching workflow behind symptom search.

    1 USER ENTERS KEYWORD
    ↓
    2 KMP receives the pattern
    ↓
    3 Searches the Symptoms field
    ↓
    4 Uses LPS to avoid unnecessary comparisons
    ↓
    5 Matching diseases are found
    ↓
    6 Medical results are displayed

    What is LPS?

    "LPS stands for Longest Prefix Suffix. KMP uses the LPS array to know how far it can move the pattern when a mismatch occurs, avoiding unnecessary comparisons."

    Pattern:
    A B A B
    LPS:
    0 0 1 2
